# JavaScript-Projects-for-Beginners
 


<h1> JavaScript Projects </h1>

This repository contains several JavaScript-based projects showcasing different interactive applications and games. <br>

<h1> Projects Included <h1>

<h2> Notes App <h2>

A simple web application for creating, editing, and deleting notes using HTML, CSS, and JavaScript.

A web-based version of the classic hand game. Play against the computer with real-time feedback and score tracking.
