<h1>Tic Tac Toe Game </h1>
<h2>Description </h2>
The Tic Tac Toe Game is a web-based implementation of the classic two-player game, built using HTML, CSS, and JavaScript. This interactive application allows users to play Tic Tac Toe against another player, with real-time game updates and win detection.

<h2>Features </h2>

Two-Player Mode: Play the game with a friend on the same device.
Interactive Grid: Click on the cells to make a move.
Real-time Updates: The game board updates instantly after each move.
Win Detection: Automatically detects and announces the winner or if the game ends in a draw.
Reset Option: Ability to reset the game and start over.
Responsive Design: Accessible on various devices, including desktops, tablets, and smartphones.

<h2>Technologies Used </h2>
HTML: Structures the web pages. <br>
CSS: Styles the application for an appealing user interface. <br>
JavaScript: Implements the game logic, including move validation, win detection, and game reset. <br>
