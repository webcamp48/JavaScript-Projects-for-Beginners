
<h1>Rock Paper Scissors Game</h1>
<h2>Description</h2>

The Rock Paper Scissors Game is a classic hand game brought to the web using HTML, CSS, and JavaScript. This interactive web application allows users to play the game against the computer, providing a fun and engaging experience with real-time feedback and score tracking.

<h2>Features</h2>
Play the Game: Choose between rock, paper, or scissors to play against the computer.
Computer Opponent: The computer randomly selects its move.
Real-time Feedback: Instant display of the results (win, lose, or draw) after each round.
Score Tracking: Keep track of the user and computer scores throughout the game.
Responsive Design: Accessible on various devices, including desktops, tablets, and smartphones.

<h2> Technologies Used </h2>

HTML: Structures the web pages.
CSS: Styles the application for a visually appealing user interface.
JavaScript: Implements the game logic, including move selection, result calculation, and score tracking.

 <h2>How to Play </h2>

1. Open the `index.html` file in a web browser that supports JavaScript. <br>
2. Click on one of the provided options: rock, paper, or scissors. <br>
3. See the game's outcome displayed on the screen. <br>
4. To reset the game, click the "Reset Game" button at any time. <br>

Enjoy playing Rock Paper Scissors! <br>
